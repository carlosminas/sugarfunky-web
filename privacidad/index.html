Privacidad de Jarvis

Última actualización: 6 de noviembre de 2026.

Esta política explica cómo trata los datos Jarvis, el asistente personal privado de los responsables de Sugar Funky. Jarvis solo tiene un usuario, su propietario, y solo accede a las cuentas que ese usuario autoriza.

Datos a los que accede

Con la autorización del propietario, Jarvis usa el permiso de solo lectura de la API de Gmail (gmail.readonly) para consultar sus correos. No puede enviar, modificar ni borrar correos.

Cómo se usan

Los datos se usan únicamente para ofrecer al propietario las funciones que pide, como resumir correos o buscar información en ellos. Se guardan solo en su servidor privado, en la medida en que sean necesarios para esas funciones.

Con quién se comparten

Para generar respuestas, el contenido necesario se envía a la API del proveedor de inteligencia artificial que usa Jarvis, actualmente Anthropic. No se venden datos ni se comparten con otros terceros, ni se usan para publicidad.

Datos de usuario de Google

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.

Eliminación y revocación

El propietario puede revocar el acceso en cualquier momento desde los permisos de su cuenta de Google y borrar los datos guardados en su servidor.

Contacto

Para cualquier duda sobre esta política, escribe a info@sugarfunky.es.
